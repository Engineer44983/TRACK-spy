# 🔍 Network Web Monitor

[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Kali Linux](https://img.shields.io/badge/Kali-Linux-557C94?logo=kali-linux)](https://www.kali.org/)

Advanced network monitoring tool that detects website visits on your local network.

## ✨ Features

- 🔍 **Real-time monitoring** of HTTP/HTTPS traffic
- 📡 **DNS query detection** for all devices
- 🔔 **Instant notifications** for targeted sites
- 📊 **Detailed statistics** and reporting
- 🌐 **Web interface** for remote monitoring
- 🔒 **Secure** and privacy-focused
